How does the {{ system }} rating system work?
{% if system == 'elo' %}

Elo — Each player starts at 1500. After every match the winner gains points (and the loser loses the same amount). The K-factor is 32. The amount of points exchanged depends on the expected outcome: beating a much stronger player earns more points than beating a weaker one. A draw gives each player half the expected exchange.

{% else %}

Glicko-2 — Extends Elo with a Rating Deviation (RD) that measures uncertainty, and a volatility that tracks rating consistency. Players start at 1500 ± 350 RD. The rating converges as more games are played. A high RD means the rating is less reliable.

{% endif %}
